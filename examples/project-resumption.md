# Example: Project Resumption

A project should be resumable without reconstructing its entire history.

```text
Project: Policy Review

Objective: Complete the current policy review.

Current state: Requirements have been collected and the draft structure is complete.

Last completed action: Mapped identified requirements to the draft sections.

Next physical action: Open the draft and complete the remaining requirements mapping.

Open questions:
- Which requirements still need authoritative confirmation?
- Which items should be deferred to the next review cycle?

Blockers:
- One source document is still missing.

Relevant files / links:
- Policy draft
- Requirements register
- Source documents

Important decisions:
- Keep unresolved items visible rather than guessing.
```

The important property is not the format itself. It is that the next return to the project has a clear entry point.
