# 04. Cloud Infrastructure Mapping (AWS Analogy)

Mapping human cognitive failure modes to distributed systems engineering allows us to apply proven resilience patterns to personal productivity.

---

## System Mapping Table

| Cognitive Failure Mode / Pattern | AWS / Distributed Systems Equivalent |
| :--- | :--- |
| **Immediate Memory Wipe on Interrupt** | Volatile Cache Flush (ElastiCache Node Crash) |
| **Out of Sight, Out of Mind** | Unindexed S3 Bucket Storage (No Query Layer) |
| **Executive Dysfunction / Paralysis** | Thread Starvation / Deadlock in Event Loop |
| **Hyperfocus State** | Dedicated On-Demand GPU Compute Cluster |
| **Context-Switching Exhaustion** | High Cold-Start Latency (Serverless AWS Lambda) |
| **Distracting Peripheral Ideas** | Unhandled Event Stream / High Network Noise |
| **Emergency Task Recovery** | State Checkpointing & Dead Letter Queues (DLQ) |

---

## System Analogies Explained
* **ElastiCache Flush:** An unexpected interruption clears active RAM. Without disk persistence, state is lost completely.
* **AWS Lambda Cold Starts:** Context switching carries high spinning-up overhead. Reducing context switches conserves overall energy and latency.
